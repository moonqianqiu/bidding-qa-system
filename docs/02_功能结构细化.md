> 上游文档：[01_系统框架设计.md](./01_系统框架设计.md)。本文把系统拆到**功能点粒度**：
> 8 个功能域（A~H）、每个功能点的输入输出 / 依赖 / 优先级 / 所属里程碑，以及**量化验收指标**。
> 编号规则：`域.序号`；优先级 P0（本期必须）> P1（本期尽量）> P2（明确延后）。
> **修订 v2**：新增量化验收指标表、4 个功能点（A13/B8/E7/F8）、各域细则（提示词模板/超时格式/泄漏规则/缓存键/黄金集 schema 等）。

## 0. 功能结构总图

```

├── A 前端交互           问答页·评估页·系统监控·设置·会话搜索

├── E 检索引擎(RAG)      分类·编码(API)·混合召回·精排·缓存·纠错重检·无答案缓存
```

## C. Agent 调度（agent/）

**C1 系统提示拼装模板🆕**（分节骨架，直接作为单测 fixture）：

```
[角色]   招投标领域问答助手：只依据取数结果作答；材料未覆盖→「未包含」；数字必给图表来源
[技能]   {命中技能正文（仅首轮或点名时注入）}
[前情提要] {历史压缩摘要（滚动增量）}
[澄清规则] {仅 history 为空时注入：限定条件=地区/时间/标的物任一即放行，全无→调 ask_clarification}
[工具约束] {本轮工具表+选择指引；触顶时追加「基于已有结果直接作答」约束文本}
[输出格式] 来源引用标注规范 / 图表触发规范 / 泄漏禁令（正文中禁止出现工具调用语法）
[历史消息…] {最近 N 轮}
[本轮问题] {…}
```

| 编号 | 功能点 | 说明 | 依赖 | 里程碑 | 优先级 |
|---|---|---|---|---|---|
| C1 | 上下文构建 | 按 C1 模板拼装；每节的注入条件可独立单测 | —— | M2 | P0 |
| C2 | 工具表组装 | 基础集无条件；联网工具仅开关开启挂入；澄清工具**仅首轮挂入**（提示词规则与挂载条件同源） | D | M2 | P0 |
