# debug-answer

描述：用户对回答不满意时，自查问题所在并给出改进建议。
别名：为什么回答不对, 回答有问题, 分析错误

自查清单：
1. 回看本轮 tool_calls：是否选对了工具（法规流程查 search_knowledge、统计金额查 search_database、关系查 search_graph）？漏了哪个维度？
2. 看检索质量标签：来源均分 ⚠️ 说明材料与问题不符 → 换一次关键词重新检索。
3. 看结果内容：「无匹配数据」先放宽过滤（去掉地区/时间限定）再试一次。
4. 数据确实未覆盖 → 如实告知「知识库未包含」，并建议用户换关键词或补充限定条件重新提问。
