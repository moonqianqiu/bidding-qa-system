## 2. 风险登记（触发阈值量化，动态维护）

| 风险 | 量化触发阈值 | 对策 |
|---|---|---|
| 嵌入/重排 API 配额与成本 | **周失败率 >2% 或月费用超预算 20%** | 切换 jieba BM25 灾备通道纯本地检索（ingest 已双写灾备稀疏向量）；批量入库 429 → 批大小减半+退避加倍（**会话内 429 率 >1%** 即调参） |
| 生成/判分模型 API 变动/涨价 | 判分单题失败率 >5% | 切换主槽位/判分槽位配置（通用适配器）；判分缓存按端点-模型分目录 |
| 工具循环规划质量退化 | **hit_cap 率 >10%（黄金集）** | 冻结新功能，修提示词/工具描述/循环参数 |
| 检索延迟劣化 | **P95 >1.5s 连续 3 次** | rerank 候选降档（15→10）→ 缓存扩容 → 复查嵌入 API 区域延迟 |
| 评测成本失控 | **离线单次 >¥5**；免费额度模式下单平台额度用量 **>60%** | 在线采样率默认 0（行为全量免费）；点踩仅忠实度单维；离线复用判分缓存；**额度用量每周人工巡检控制台（自动化告警延后，决策 #8），>60% 冻结批量操作** |
| 自研循环复杂度失控 | 单文件 >800 行 / 循环分支测不清 | 严格分层（调度≠生成≠执行）；先写契约测试再实现 |
| 解析质量 | 黄金集抽样解析不合格率 >10% | pdfplumber 兜底；该文档入「拒收清单」人工处理 |
| 数据保留 | —— | conversations/feedback 30 天清理（H7）；快照滚动保留 100（G5） |
