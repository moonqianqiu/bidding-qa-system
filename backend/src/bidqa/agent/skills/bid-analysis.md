# bid-analysis

描述：针对特定招投标分析任务的端到端分析指引（对比/趋势/排名类问题）。
别名：分析招投标, 采购对比, 中标趋势, 供应商分析

步骤：
1. 按用户意图选择数据源：法规流程用 search_knowledge；统计/排名/金额用 search_database；供应商或项目关系用 search_graph；时效性公开信息用 search_web。
2. 组合多次查询补齐维度：对比两家公司分别取数再合并；看趋势按时间窗过滤；看排名明确 top_n 口径。
3. 产出结构化回答：结论先行；对比用表格；排名/趋势给出图表要素（类型/标题含口径与时间窗/数据项）。
4. 数字结论必须标注来源 [n] 或图表；数据缺失的维度如实说明「知识库未包含」，绝不编造。
